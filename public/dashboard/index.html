    Alertes Follow / Sub

    Personnalise les messages et sons déclenchés par les événements Twitch.

    Variables : {game} {unlocked} {total}. Pas de son pour ce type d'alerte.

    Variables : {raider} {viewers} {game}. Pas de son pour ce type d'alerte non plus.

    Variables : {level} {goal} {total} {topContributor} {topContributorTotal}. Pas de son sur ces alertes non plus.

    Variables disponibles : {user} {tier} {months} {recipient} {bits} {totalFollowers} {followsThisStream}

    {totalFollowers} et {followsThisStream} ne sont utilisables que dans le message de follow.

    Un son MP3 est optionnel pour chaque type d'alerte : il est joué sur l'overlay en plus du message.
